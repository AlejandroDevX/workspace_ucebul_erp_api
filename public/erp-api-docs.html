MVP Contratos y Otrosíes

Documentación base de la API Laravel para terceros, contratos, otrosíes, documentos, aprobaciones, comentarios y flujos bajo el prefijo /api/erp.

Notas

  • El ERP no crea usuarios ni login propio.
  • Los IDs de usuario global del Workspace se leen desde X-Workspace-User-Id o desde el payload.
  • Al crear contratos y otrosíes se genera un proceso asociado automáticamente.
  • Los consecutivos iniciales son PR-, CT- y OT-.

Contratos

GET /api/erp/contracts Lista contratos
POST /api/erp/contracts Crea contrato y proceso 
{
  "erp_contract_contractor_id": 1,
  "erp_contract_title": "Contrato de prestación de servicios",
  "erp_contract_object": "Apoyo operativo",
  "erp_contract_total_value": 15000000,
  "erp_process_priority": "medium"
}
POST /api/erp/contracts/{contract}/move-step Mover paso 
{
  "erp_workflow_step_slug": "documentation_review"
}
POST /api/erp/contracts/{contract}/close Cerrar proceso
